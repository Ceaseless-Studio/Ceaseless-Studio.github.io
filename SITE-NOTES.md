# Ceaseless Studio Site - что уже сделано

Живой сайт: https://ceaseless-studio.github.io/
Репозиторий: `CeaselessStudio/CeaselessStudio.github.io` (локальная папка `Cealess Studio Site`).
Стек: статический HTML, CSS и JS, без сборки. GitHub Pages.
Текущая неоновая итерация: ветка `site/neon-signs`, в `main` не слита.
Последнее обновление: 2026-11-09.

## Как пользоваться этим файлом

- Перед правками сайта прочитай раздел «Что уже сделано» и «Не предлагать снова».
- После каждой правки допиши строку в «Журнал»: дата, что изменилось, файлы, коммит.
- Если фича меняет поведение, обнови и список «Что уже сделано».
- `style.css` в смешанной кодировке: не редактировать. Новые стили - отдельным CSS-файлом.
- Проверка JS: `node --check site.js`.
- Предпросмотр: из корня сайта `python -m http.server 8765 --bind 127.0.0.1`, затем http://127.0.0.1:8765/ и Ctrl+F5.
- Пуш в `main` - только по прямой просьбе. Текущая неоновая ветка тестовая.

## Что уже сделано

### База и атмосфера

- Готический клоун: чёрно-белая гамма, багровый акцент `#992D22`, Pirata One и Cormorant Garamond.
- Ночной режим с переключателем в меню, затемнение, виньетка.
- Занавес на переходе между страницами.
- Билет `ADMIT ONE`, который влетает один раз за визит и улетает по клику.
- Вывеска `APPLAUSE` в подвале: бегущие лампочки и `bravo` по клику.
- Карта судьбы: колода, переворот, ответ на английском и русском.
- Демо-чат с Марией: фиолетовая панель, пузыри, быстрые вопросы, индикатор набора.
- Контракт на странице бота: бумага, пункты, холст для подписи кровью.
- 404: пустая клетка, бумажная записка `gone.` между прутьями, дверной зазор.

### Старая итерация (до неона)

- Шёпот через 10 секунд бездействия: держится 6 секунд, повтор не раньше 30, любое движение мыши или клавиша убирают.
- Konami-код `↑↑↓↓←→←→BA`: еле заметная подсказка в подвале каждой страницы, срабатывание по физическим клавишам (работает на русской раскладке), глитч на 2,7 секунды и надпись `cheat code accepted`.
- Одна из записок цитирует старый код.
- Баннер в README заменён свежим кадром шапки: 1440x777.
- Соц-превью `assets/og-card.png` заменено: 1200x630.
- Старая ветка слита в `main` через PR #27 (сжатый коммит `8089544`), фикс 404 - через PR #28 (`0aa20e1`).
- GitHub Pages отдаёт `404.html` на битый адрес; скрипт определяет 404 по наличию `.cage`, поэтому записка и счётчик работают и на чужих адресах.

### Неоновая итерация (2026-11)

- Бумажные записки на главной заменены неоновыми вывесками: две в полях у блока маски на широком экране и двенадцать разбросанных по странице.
- Вывески: тёмный акрил, металлический кронштейн, гравированная плашка, багровая трубка, зажигание строк по одной, редкое проседание напряжения.
- Текст: Cormorant Garamond 600, тёплое ядро, многослойное свечение; крик - Pirata One; зачёркнутое слово - потухшая трубка.
- Ночной режим усиливает свечение; при `prefers-reduced-motion` анимации выключены; без JS виден запасной текст.
- Широкий брейкпоинт 1560px, на узких экранах вывески уходят в обычный поток.
- Охота: пять спрятанных неоновых вывесок `OPEN` на пяти страницах, финальный диалог «Все пять горят.».
- Афиша `ГАББЕР` переделана из бумаги в неоновый лайтбокс: акрил, кронштейн, трубка-рамка, светящийся заголовок, припев и `ебашь ещё`.
- 404: добавлена маленькая неоновая табличка `NO SIGNAL` с улыбкой. Клетка и бумажная записка остались на месте.
- Счётчик охоты: вместо текста пять трубок, каждая зажигается за найденную вывеску. Для скринридера текст сохранён.
- Логотип-улыбка: перед заголовками разделов вместо ромба, водяным знаком на контракте, штампом на афише, в счётчике и на табличке 404.
- Неона в этой партии добавлено ровно две вещи: табличка на 404 и трубки счётчика. Остальное - плоский багровый знак без свечения.
- На странице Марии - фиолетовая вывеска `ON CALL` / `after hours` с подписью: одна штука в правом поле героя, на узких экранах скрывается.
- На странице Ceaseless Bot - две вывески: русская `ЗА КУЛИСАМИ` с репликами «киска, я на смене.» и «кнопки не трогай.» слева и английская `BACKSTAGE` с `kitten, I'm on shift.` и `hands off the buttons.` справа; подпись `Ceaseless`. На узких экранах обе скрываются.
- На странице Driven By Desire - золотая табличка под ключевым артом, только по-английски: `MAIN STAGE`.
- Логотип в шапке зажигается при загрузке: короткое мерцание трубки, на первом заходе ждёт занавес, при `prefers-reduced-motion` выключено.
